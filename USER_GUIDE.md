# LT5Lyrics 1.11.7 for Minecraft 26.3

A client-side Minecraft Fabric mod for a music HUD, synchronized lyrics, normal 3D world lyrics, and distant Sky Lyrics. The compiled JAR is provided separately; you **do not need a GitHub account or to build the source** to use it.

## Install the ready-to-use mod (Windows)

1. Install **Minecraft: Java Edition 26.3** and [Fabric Loader](https://fabricmc.net/use/installer/) for that exact Minecraft version. The build was made with Fabric Loader **0.20.1** and Java **25**.
2. Download a **Fabric API** release for Minecraft **26.3** (version **0.165.0+26.3** or newer compatible release) from its [Modrinth page](https://modrinth.com/mod/fabric-api/versions?g=26.3&l=fabric).
3. Put the supplied **`lt5lyrics-1.11.7+mc26.3.jar`** and the Fabric API JAR in `%APPDATA%\.minecraft\mods`. Remove older LT5Lyrics JARs from that folder first. Do not put the source ZIP or `-sources.jar` in `mods`.
4. Launch the Fabric 26.3 profile. Start Spotify or a supported browser's YouTube/YouTube Music playback on Windows, join a world, and press **U** to open LT5Lyrics Studio. Some browsers or tracks may not expose a usable Windows media session; if no song appears, try another supported player/browser and make sure audio is actually playing.

**Keybinding when upgrading:** This version defaults to **U** because Minecraft uses O for Friends. Minecraft can keep your previous saved O binding: if U does not open the Studio, go to Options → Controls → Key Binds, find LT5Lyrics → Open Settings and assign U (or another free key). You can also open chat with T, click the island, and choose Open Settings.

The included native media-session library uses Windows SMTC; the existing non-Windows backend does not detect desktop players. Fabric and the settings can load on other platforms, but Spotify/YouTube detection and playback control on macOS/Linux are **not implemented**. The mod does not log in to music services or bypass their restrictions.

## New in 1.11.6 — simultaneous players and fixed 3D placement

* **Two or more playing sources:** With automatic player selection, the mod keeps the current player if it already has displayable lyrics. If it does not, the mod checks other **playing** sessions exposed by Windows and chooses one with playable lyrics. It switches the entire selected player, so the title, playback controls, playback clock and lyrics all refer to the same session. A line-timed result can appear while a compatible word-timed result is still being checked. If more than one player has lyrics, the first usable result found can win; the mod then keeps that player while it is playing and has lyrics.
* **Choose a player yourself:** Open chat and expand the music bar, then use its player-source button; or press **U → Advanced → Music & Lyrics Sources → Switch Player**. Manual selection is respected while that player is playing. Continue cycling after the last player to return to **Automatic (lyrics first)**. If the selected player stops while another is playing, the playing one can take over. A chosen manual lyric result or local LRC remains authoritative for its current track.
* **Privacy and availability:** To find lyrics for another active session, its artist/title (and duration when available) is sent to your **enabled lyric providers**. The mod searches at most one alternate session at a time and temporarily caches results and misses; it does not search paused sessions. Some browsers or Windows versions expose only one media session for multiple tabs, and some players provide incomplete metadata. If Windows does not expose a session, the mod cannot select it. A provider may have no match or be unavailable; metadata and lyric timing can still be wrong. This feature uses the existing Windows SMTC bridge and is not a new macOS/Linux media backend.
* **Fixed World lyrics:** Corrected the fixed-mode height calculation for curved/wrapped text, and stopped new groups from climbing tall walls/trees into the sky. A blocked spawn may move to a nearby clear spot on the same side, within three blocks, but an existing fixed group or locked X/Z never starts following or gets moved. Follow and Sky placement calculations are unchanged. If every nearby column is obstructed, the group stays near the player's feet and may be hidden by blocks.

## New in 1.11.4 — quick lyric timing on the island

1. Start a song and join a world. Press **T** to open chat, then click the music island at the top to expand it. The timing buttons are right above the existing playback controls.
2. Use **−1.0 / −0.1** to make lyrics appear later, or **+0.1 / +1.0** to make them appear earlier. The amounts are seconds. The **LYRIC** value is the total in use; **TEMP** is the temporary island adjustment. All lyric displays use the same total, while the playback clock stays unchanged.
3. **RESET** clears only TEMP, immediately returning to any previously saved per-song timing. It does not erase that saved timing. TEMP also clears when the estimated playback clock reaches the reported song duration, on a reported end or track change, on restart/repeat, or after the media session disappears; pausing or an ordinary seek does not clear it. A stable jump to the beginning after 15 seconds, or near a reported end, is treated as a restart. Very short session dropouts are tolerated.
4. The old per-song timing controls and selected-line tap sync are still available in Studio. When you use those **saved** controls, the current total is saved for the song and the temporary portion is cleared. A tap computes a fresh total from the unadjusted playback clock. If you want the quick adjustment to remain temporary, don't use the saved controls for it.

A player that never reports an end, track change, restart or session loss cannot reliably signal when to reset; in that case use RESET. A single offset cannot repair individually incorrect word timestamps or guarantee a match to the recording. On a very short window the island temporarily omits its progress strip and may show fewer lyric lines to keep the buttons reachable.

## New in 1.11.3 — compare lyric timing from more sources

**Unison** and **AMLL TTML DB** are now included as additional keyless community sources. They start enabled; existing provider order and your saved preferences are preserved, with newly added sources appended for existing installations. The mod checks their reported artist/title, version and available duration before accepting a result. Some songs will not be found, and an unknown duration or ambiguous version can still lead to a wrong match.

1. Play a song and open **U → Extras & Tools → Lyrics → Compare enabled sources**. If the automatic search is still running, wait for it to finish and press Compare. Use **Previous source / Next source** to browse the results. Scroll over the page if the controls do not fit.
2. **Word timing on X/Y lines** means the response actually contains separately timed word/syllable segments on X of Y lines; it does not mean every word is accurate. **Line timing; words estimated** means the moving highlight is estimated within each line. Other outcomes include plain lyrics, no match, disabled, unavailable/rate-limited or an optional key needed. The comparison sends the current song's artist/title (and duration when available) to the enabled services. It does not change the current lyrics or test sound.
3. To change which sources can be chosen, go to **U → Advanced → Music & Lyrics Sources** and enable, disable or reorder them. Leave **Prefer Word Timings** ON to look for compatible word-timed results; use **Retry Lyrics** if needed. Your manually chosen LRCLIB result and local LRC retain precedence. If no source has genuine word timestamps, the existing estimated sweep remains.

**This compares timing data, not the singer's audio.** A word-timed result may still be early, late, incomplete or for a different edit. Try the existing per-song timing offset or selected-line tap sync; a single offset cannot fix inaccurate individual word timings. Coverage and service availability vary.

Lyrics displayed from Unison include its required on-screen credit: **Lyrics from Unison (https://unison.boidu.dev)**. Its [database and attribution terms](https://github.com/better-lyrics/unison) and the [AMLL community database terms](https://github.com/amll-dev/amll-ttml-db) apply separately from any rights in the songs' lyrics. No lyrics database is bundled with this mod.

## New in 1.11.1 — more accurate karaoke highlighting

The moving highlight now follows real word/syllable timestamps when the chosen lyric source supplies usable timing. This applies to the top music bar and World/Sky lyrics. A line without usable word timing still gets the **estimated moving sweep**; it is not word-perfect. A source may have word timing for only some lines.

1. Press **U → Advanced → Music & Lyrics Sources**. Leave **Prefer Word Timings** ON (the default) and enable the providers you want to use. The first line-timed result can appear while the mod checks other enabled sources; if a compatible word-timed result is found it replaces that result. Source order breaks ties. Switching the preference OFF restores first-timed-result priority. Your manually selected LRCLIB result or local `.lrc` file remains authoritative until you change it or reload.
2. The status card identifies **Word timing where available**, **Line timed; words estimated**, or plain/estimated lyrics. Real word timing can come from LRCLIB Lyricsfile records, BetterLyrics TTML, restricted Lrcmux results, and supported existing word-timed LRC or other providers. Not every song has word data; some BetterLyrics requests require your optional key, and sources can be unavailable or rate-limited. A mismatched cross-source upgrade may be rejected rather than risk displaying a different version. Searching more enabled sources can take longer and shares song metadata with those services.
3. If the lyrics as a whole are early or late, use **Advanced → Lyrics → Song Lyric Timing** or **Extras & Tools → Timing** to adjust the current song. A **positive** offset moves the words earlier; a negative offset moves them later. In Extras & Tools you may also select a line with Previous/Next, then tap when the singer starts that chosen line. An overall offset cannot correct badly timed individual words or a different song edit.

The playback bridge reports whole seconds, so the mod estimates the fractional position between updates. Provider timestamps, the source recording, video intros, audio device latency and clock precision can all affect alignment. This improves the available timing but **cannot guarantee perfect synchronization**. Real Windows Spotify/YouTube audio was not tested in the build environment; see `VERIFICATION.md`.

Like other size changes, very large text can intersect terrain or be clipped. **Find arrow** shows a passive screen-edge marker when the center of fixed World lyrics is off-screen. It is not shown for Follow or Sky, and it never replaces the crosshair or intercepts clicks.

Some sessions cannot be identified and show no badge.

For tap-to-sync, start a song, choose the actual timed line with Previous/Next (or -5/+5), and press **TAP** or **Space** exactly when you hear that line start. This sets the existing per-song offset, limited to -10 through +10 seconds. It does not rewrite the LRC; human reaction time and the player's reported clock can affect accuracy. Estimated-pace lines remain estimates.

It is used for the current play, not saved as a permanent provider preference; **Retry all** returns to automatic matching. Other providers still work as before. Plain results are identified as plain, not genuine timed lyrics; optional Auto-Pace remains an estimate. The song/source changing during a search cancels the old result.
* **Import LRC:** in Lyrics, play the song first and choose **Import LRC**. Select a UTF-8 `.lrc` with timestamps. Its original content, including supported enhanced word tags and translation lines, is copied without reformatting to the current song's local lyrics folder; an existing local LRC is backed up as `.before-import` (or a numbered variant). The desktop file chooser depends on the operating system's dialog support; on Linux, SDL may need an XDG desktop portal or Zenity; dialog features depend on the OS backend.

Local `.undo` and `.studio-backup` files can contain your API keys: **do not share them**. Style exports are separate and exclude keys.

## Use the Customization Studio

Press **U** or use `/lt5` to open the Studio. The prominent **Simple / Advanced** selector at the top is remembered between launches. The views use the **same settings**: switching views does not change your lyrics or reset anything. Scroll to see controls that do not fit in the panel.

### Simple: everyday choices

* **Lyrics:** turn lyrics on or off without turning off the music bar; choose **World**, **Sky**, or **Top Bar**; show translations; and, for World, choose Left, Right, or Alternate for new lyric groups. Choosing Top Bar also shows the music bar.
* **Sky:** appears when Sky lyrics are selected. Choose whether to follow your look direction horizontally, choose Near/Medium/Far distance, and show or hide previous/next lines and the song title.
* **Appearance:** choose Small/Medium/Large text for World or Sky, a text color, and (for World) an Off/Soft/Strong background. The Top Bar has no actual text-size setting, so Simple does not offer a misleading size control there. Existing Advanced scale multipliers still affect the result.
* A value changed to something outside these choices in Advanced is shown as **Custom** in Simple. Merely opening the page or switching views does not overwrite it. A Simple color choice changes the active primary lyric color; separate Advanced colors and effects remain available.
* **Reset → Reset Simple Settings** asks for confirmation and resets **all Simple choices**, including ones on currently hidden World/Sky pages. It keeps unrelated detailed settings, sources, API keys, song timing, custom files, the selected UI mode, and music-bar visibility. The magnitude of the World side offset is kept, though its side is reset.

### Advanced: every detailed setting

Select **Advanced** at the top. The five full categories are **Appearance**, **Lyrics**, **Sky Lyrics**, **Music & Lyrics Sources**, and **Advanced**. This view retains precise sliders and values, color controls, effects, animations, provider settings, per-song timing, search, category resets and the existing music-bar controls. Its last category is remembered separately from the Simple/Advanced choice.

* **Appearance** has the color wheel, brightness, text size, glow, and detailed HEX/RGB, separate colors, glow and outline controls. Changes apply live and are saved.
* **Lyrics** controls display style, translations, animation and per-song timing. **Sky Lyrics** controls its fixed height, distance, size, follow, context and other Sky options. The Studio preview is a **2D illustration**, not the game camera; it cannot simulate terrain, FOV, fog, shaders or exact GPU output.
* **Music & Lyrics Sources** shows the current result and lets you enable providers or use Up/Down to change priority. Timed lyrics are preferred over plain lyrics, even if a plain-only source is higher in the list. With Prefer Word Timings enabled, compatible word-timed sources are preferred over line-timed sources; provider order breaks ties. Auto-Pace is an **estimate**, not genuine sync. Use **Retry Lyrics** if a source or network was temporarily unavailable.
* Type in **Search** to find settings across categories; use **Back** to return. In the full Studio, **Ctrl+F** or **/** focuses search; **Tab/Shift+Tab** focuses visible controls, **Enter/Space** activates them, **Left/Right** changes tabs (or adjusts a focused slider/color wheel), **Up/Down** scrolls (or adjusts the focused wheel), **Page Up/Down** scrolls farther, **Ctrl+Tab** changes categories, and **Esc** cancels editing or a confirmation. In a text field, **Ctrl+A** selects text and **Ctrl+V** pastes. The compact music-bar settings panel also supports the mouse.
* Category resets require confirmation. **Restore Appearance Defaults** keeps providers, keys and HUD position; the source-category reset keeps personal keys. **Advanced → Reset All Settings** is a separate confirmed factory reset that also removes saved API keys and all saved per-song timing offsets; custom lyric and font files are not deleted.

### Holograms and normal gameplay

World and Sky lyrics are **visual only**. They cannot be clicked or dragged, and they do not intercept right-clicks, button releases or the scroll wheel, so you can use items, eat, block with a shield and place blocks while looking through them. The old right-click-and-hold hologram drag was removed for this reason. Use the World and Sky settings to adjust their placement instead. The music bar and Studio remain interactive.

## Normal 3D World Lyrics — new in 1.6.0

1. Join a world, press **U**, select **Advanced**, open **Lyrics**, and select **3D World Lyrics**. Scroll down to **Normal 3D World Lyrics**. These controls do not change Sky Lyrics or the top HUD.
2. **Normal 3D Distance** is the forward distance in blocks (2–24, default 6). With Follow off it is measured horizontally from the player, so looking up or down does not drive a new group underground. With Follow on it is measured from the eye along the camera's 3D direction, as before. **Normal 3D Offset** is the signed horizontal distance to the side: minus means left and plus means right. Its magnitude is at least 1.25 blocks (default +3.5); zero is not allowed. These are world-space measurements, not HUD coordinates.
3. Choose **Left**, **Right**, **Alternate**, or **Random**. Left/Right override the sign; moving the signed offset across zero also changes a fixed side. Alternate starts on the offset's sign and then switches on each new group. Random is chosen once per group. All wrapped rows and translations share that group's side. Distance, offset and side changes apply to **new** groups; wait for the next line or briefly switch display modes and back.
4. **Normal 3D Text Size** changes the actual world size of the letters, not their spawn location. The global Appearance Text Size and the older advanced hologram scale also multiply this size. **Words Per Line** defaults to 5; existing line breaks are retained, and translations wrap underneath. **Normal 3D Line Spacing** adjusts the gap. A word is never forcibly split; languages or strings without breakable spaces may remain one very long row.
5. Turn **Normal 3D Curvature** on for real 3D bending, then adjust **Curve Amount**. Zero or the toggle off produces a flat line. The group anchor does not move when size or curvature changes. **Hide Lyrics Behind You** is on by default: groups whose anchor is behind the actual viewing direction are skipped without being moved. Turning it off removes this extra culling; Minecraft still normally clips objects behind the camera.
6. **Follow Camera Gaze** is off by default: a new group is placed near the player's **feet level**, with its wrapped text and translation above that level even when you look down. The group stays at its spawn coordinates until it ends, while rotating to face the camera. If you move up after it has spawned, it does not follow you upward. Turning Follow on makes active Normal groups update continuously as you move or turn, including when the previous position is behind you; its existing pitch-following placement is unchanged. Your saved distance and side still apply. When Follow is off, the group-level rise/lift is suppressed to keep the anchor fixed; fade, scale, karaoke and other compatible effects remain. Your choice is saved.

**Crosshair:** Normal 3D lyrics and their effects no longer have a circular cutout around the middle of the screen. Minecraft's ordinary crosshair still draws over the world, so its own small pixels can cover what is directly behind it.

Lyrics can also be outside the field of view when you turn or move away from a fixed world anchor, hidden behind you when **Hide Lyrics Behind You** is on, covered by blocks, or absent during a blank timed-lyric entry. A very large side offset, narrow FOV, large text, or an exceptionally long unbroken word can put some text off-screen. Try turning **Follow Camera Gaze** on if you want Normal groups to follow your view; or reduce the side offset, text size, or words per line. These settings do not change Sky Lyrics.

For fixed Normal lyrics, the mod checks loaded collision shapes at the requested spawn column and rises at most one block above the player's feet to accommodate a step or slab. If a tall obstacle blocks that column, it searches for a nearby loaded site (up to three blocks away, on the same side and still ahead); if none is open, it retains the requested position near the feet and the lyric may be hidden by the wall. It never searches downward below the player's feet. Over a drop or while flying, that rule can leave the group floating instead of touching the lower terrain. With a locked position, a later group keeps the locked X/Z and may be raised when needed, but an already visible group never moves. This is best effort: unloaded chunks, ceilings, slopes across the width of the text, oversized text and other blocks can still obscure part of a group. Minecraft's field of view can also place a ground-level lyric off-screen if you look straight down or up. Enable **Advanced → Visible Through Walls** only if you want normal lyrics visible through blocks. Settings are saved automatically in `.minecraft/config/lt5lyrics/settings.json`.

## Sky Lyrics — one centered location and horizontal follow (1.8.0)

1. Start a song, join a world, and press **J** to enable Sky Lyrics. Press **U** and select **Sky** in Simple, or select **Advanced → Sky Lyrics** and scroll or search for **Follow Look Direction**.
2. The active lyric and its translation share one centered, world-space location. When a new timed lyric starts, it replaces the current group at that same location rather than spawning at a random direction or depth. Long lines automatically wrap into centered rows; the words keep their original timestamps and karaoke timing. Long translations wrap beneath the active line. Exceptionally large wrapped groups can be made smaller automatically to help them fit.
3. With **Follow Look Direction ON**, turning left or right smoothly moves the slot around you horizontally. Looking up or down does **not** move its world height. It is not a screen overlay: if you look far above or below its fixed height, it can leave the screen. With follow **OFF**, the slot stays at its world position, subject to the safety boundary. Follow defaults **OFF** for a new setting, but your previously saved ON/OFF choice is retained. In Advanced, Sky Height changes the slot's height explicitly; holograms can no longer be dragged. At the boundary or after extreme movement/teleportation the safety clamp can temporarily alter its position, including Y.
4. **Show Previous & Next Lines** is optional context: at most one fading previous line appears above and one next preview below the complete current group. The existing default is ON; switch it **OFF** to display only the current lyric and translation. **Show Song Header** controls the separate song title/artist that can appear above the lyric early in the track; turn it OFF as well if you do not want it. Context or the header can fade out when they would overlap the active lyric or be clipped by the screen. They are not duplicate copies.
5. **Sky Lyrics Distance** is the player-centered horizontal boundary radius (80–1000 blocks; default 360), not its diameter; distance changes are eased. **Sky Lyrics Text Size** is the preferred size, not the distance; long groups can be reduced to fit. **Sky Height** sets the intended height when changed. **Sky Arc Curvature** and the existing colors, glow, outline, translations and animation remain available. The former Sky Drift Speed control has been removed because the active group no longer drifts; an old saved `skyDriftSpeed` value is kept for compatibility but ignored.
6. Blocks can hide Sky Lyrics. If desired, enable **Advanced → Sky Lyrics → Visible Through Mountains & Roofs**. The 3D effect and occlusion can differ with your GPU, graphics mods, shaders, FOV and world. Wrapping/fit estimates use your configured FOV, not temporary zoom or animation effects. Very long shaped scripts that cannot be safely split may be reduced to fit; fonts may not contain every character or emoji. Text can still leave the screen if you look away from its fixed height or at extreme settings.

The Sky renderer also avoids restarting a line when an identical lyric list is refreshed and resists very small backward clock corrections across a timestamp. A backward seek landing within 0.15 seconds before a boundary may briefly retain the current lyric; a larger seek switches normally. These changes address specific reproducible cases but do not prove the cause of every intermittent duplicate or disappearance.

## Checking Sky Lyrics in your own game

1. Play a timed song, open a world with a clear view and enable Sky Lyrics with **J**. Use **Advanced → Sky Height** and **Sky Lyrics Distance** to make the location comfortable, then look toward it.
2. Turn **Follow Look Direction** ON and turn left and right: the slot should follow horizontally. Look up and down: the lyric moves on screen because the camera moves, but its world Y should not follow your pitch. Toggle Follow OFF and turn again: the slot should remain at its world position.
3. Try a long lyric and translation, turn optional context and the song header ON/OFF, then let several lines pass. If you want precisely one lyric group, turn both optional controls OFF. Try a different text size or distance if the group is hard to read.
4. Normal 3D World Lyrics and the HUD have their own settings. If a real song still duplicates or disappears, record its title, source, whether Follow/context are ON, your FOV, graphics mods and whether the lyric was behind blocks. Synthetic tests cannot cover all players and integrations.

## Lyrics sources and credentials

LRCLIB, Unison, AMLL TTML DB, NetEase, KuGou, BetterLyrics cached tracks, a restricted **cache-only** Lrcmux lookup (only its LRCLIB/KuGou sources), and Lyrics.ovh need no personal key. Availability, rate limits, coverage and accuracy vary. Lrcmux is explicitly restricted before requesting data; Genius and YouTube Music upstreams are not requested by this integration, and responses with an unapproved upstream are rejected. Lyrics.ovh is plain text. NetEase/KuGou retain the existing public endpoints; the existing KuGou search endpoint uses HTTP, so song search terms may be visible on the network. Requests use timeouts, are off the render thread, cache results and respect provider cooldowns.

* **Unison:** public [documented API](https://docs.betterlyrics.org/unison), no key required. Displays the required attribution whenever Unison lyrics or retained translations are shown; the server may rate-limit requests.
* **AMLL TTML DB:** public [documented HTTP API](https://amll.dev/en/reference/http-api/overview), no key required. Results are community-contributed and may contain word/syllable timing, line timing or no matching track.
* **BetterLyrics:** its [documented API](https://lyrics-api-docs.boidu.dev/) serves some cached lyrics without a key; an optional personal key can allow uncached requests. In **Advanced → Optional Personal Provider API Keys**, enter/paste the key in **BetterLyrics Key**. The provider's own rules and availability apply.
* **Musixmatch:** use your own properly licensed [developer API key](https://developer.musixmatch.com/) in the **Musixmatch Key** field, and enable the provider. Many free keys provide only restricted/truncated previews; the mod does not present those as complete lyrics. No key or subscription is required for the other sources.

Keys are optional and stored **as plain text** in `.minecraft/config/lt5lyrics/settings.json`; never share that file with others. The mod does not embed credentials. The included Windows media-session bridge exposes title, artist and duration, but **not album metadata**, so album-based matching is unavailable unless the bridge is extended. Matching uses normalized titles/artists, alternate forms and duration checks where the provider exposes metadata; mistakes and unavailable results are still possible, especially with ambiguous versions or plain APIs that do not return track metadata.

## Default shortcuts

| Key | Action |
| --- | --- |
| U | Open Studio |
| J | Toggle Sky Lyrics |
| K | Play / pause supported player |
| [ / ] | Previous / next track |
| \\ | Toggle the top HUD |

`/lt5 reload` retries lyrics, `/lt5 delay <seconds>` adjusts timing, `/lt5 sky` toggles the sky mode, and `/lt5 np` displays the current song. Custom synced `.lrc` files and timing offsets are stored in `config/lt5lyrics`; legacy `config/song-island` data is migrated when applicable.

## Building from source (optional)

On Windows, install a **JDK 25**, extract the source ZIP, and double-click `BUILD_MOD.bat`. Alternatively run `./gradlew build` from the project folder. The first build downloads Gradle, Minecraft/Fabric dependencies and mappings and requires an internet connection; no GitHub account is required. The built mod is `build/libs/lt5lyrics-1.11.7+mc26.3.jar` (not the `-sources` JAR). `./gradlew checkBtp` runs the headless checks, and `./gradlew probeLyricsSources`, `./gradlew probeWordSync`, or `./gradlew probeCommunitySources` optionally test live network services; responses depend on network and provider availability. See `VERIFICATION.md` for what was and was not checked.
